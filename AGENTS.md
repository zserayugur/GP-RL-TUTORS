# Notes for AI assistants

Before starting any task in this repository, read and follow `ai/prompts/worklog_prompt.md`.

In short:
- Read the latest entries in `log/worklog/` first (team status, decisions, who changed what).
- When you finish a task, add an entry at the top of the current user's own file in `log/worklog/` (Turkish, format in `log/worklog/README.md`) and include it in the same commit.
- Never commit data files (ASSISTments, Eedi), personal data, secrets or unverified references.
